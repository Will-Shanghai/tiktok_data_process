TikTokDailyReport 使用说明
==========================

这是给不写代码的同事看的，按下面做就行。

1. 先装什么

- Windows 同事：直接双击 `TikTokDailyReport.exe`
- 不需要安装 Python
- 只有自己打包的人才需要 Python 3.11

2. 文件怎么放

先把压缩包解压到一个固定文件夹。

把订单 CSV 放到对应目录：

```text
data\data_JP\local
data\data_JP\cross-border
data\data_JP\direct_old
data\data_JP\direct_new
data\data_VN\local
data\data_VN\cross_border
data\data_MX\local
data\data_MX\direct_old
data\data_MX\direct_new
```

文件放错目录，程序就会按错店铺算。

3. 怎么运行

双击 `TikTokDailyReport.exe`。

程序会让你选国家或店铺，按提示输入数字就行。

4. 结果在哪

结果会放在 `result` 文件夹里。

文件名一般会包含：

- `Daily_Performance_Report_JP`
- `Daily_Performance_Report_VN`
- `Daily_Performance_Report_MX`

5. 常见问题

- 没有结果：先看 `data` 里有没有 CSV，再看目录放对没有
- 找不到配置：看 `config/app_config.xlsx`、`config/cache`、`config/.env`
- 某一列不存在：重新从 TikTok 后台导出 CSV，不要手改表头
- 文件夹为空：这个目录里没有 CSV，放进去再跑

6. 一般不用改

- `config/app_config.xlsx`
- `config/.env`
- `config/cache`

如果这些要改，找负责配置的人。
