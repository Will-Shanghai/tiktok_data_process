TikTokDailyReport 使用说明
==========================

1. 先装什么

- Windows 同事：下载后先解压，再双击里面的 TikTokDailyReport.exe 运行
- 不需要安装 Python
- 只有自己打包的人才需要 Python 3.11

2. 文件怎么放

运行前，请先把 `.env` 放到 `config/.env`。

这个文件现在必须有，因为程序要先读飞书配置。

把订单 CSV 放到对应目录：

```
data\data_JP\local - 日本本土店
data\data_JP\cross-border  - 日本跨境店
data\data_JP\direct_old - 日本直邮一店
data\data_JP\direct_new - 日本直邮二店
data\data_VN\local - 越南本土店
data\data_VN\cross_border - 越南跨境店
data\data_MX\local - 墨西哥本土店
data\data_MX\direct_old - 墨西哥直邮一店
data\data_MX\direct_new - 墨西哥直邮二店
```

文件放错目录，程序就会按错店铺算。

3. 怎么运行

双击 `TikTokDailyReport.exe`。

程序会让你选国家或店铺，按提示输入数字就行。

4. 结果在哪

结果会放在 `result` 文件夹里。

文件名一般会包含：

- `Daily_Performance_Report_JP`
- `Daily_Performance_Report_VN`
- `Daily_Performance_Report_MX`

5. 常见问题

- 没有结果：先看 `data` 里有没有 CSV，再看目录放对没有
- 找不到配置：先看 `config/.env` 在不在，再看 `config/app_config.xlsx` 和 `config/cache`
- 某一列不存在：重新从 TikTok 后台导出 CSV，不要手改表头
- 提示 `SKU ID` 没有匹配到成本：说明飞书配置里没找到这个 SKU，先检查 `SKU ID` 是否写对，再检查对应产品成本有没有配置
- 提示 `产品成本` 为空：说明这个 SKU 在飞书配置里没有成本，补上 `产品成本(元)` 后再跑
- 提示 `物流成本` 为空：说明这个 SKU 的物流信息没配全，检查 `计费重kg`、`头程物流成本(元)`、`尾程物流成本(元)` 或相关物流列
- 提示 `实重/长宽高` 缺失：说明该 SKU 的重量信息不完整，先补飞书配置再重新运行
- 提示 `进口IVA` 为空：说明飞书里没有这条 IVA 记录，程序会按默认公式重新计算
- 文件夹为空：这个目录里没有 CSV，放进去再跑

6. 一般不用改

- `config/app_config.xlsx`
- `config/.env`
- `config/cache`

如果这些要改，找负责配置的人。
