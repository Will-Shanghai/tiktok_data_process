TikTokDailyReport 使用说明
==========================

一、这个程序是做什么的
----------------------

这个程序用于生成 TikTok Shop 订单成本日报/周期报表。

它会读取 data 文件夹里的 TikTok Shop 订单 CSV 文件，然后自动生成 Excel 报表到 result 文件夹。

重要说明：

报表里的“利润”“利润率”不是最终财务利润。
它只是用销售额减去当前程序已经配置的产品成本、物流成本、寄样成本后得到的预估毛利。

成本计算方式：

1. 产品成本按销量计算。
   例如卖出 2 个鼻毛刀，就计算 2 个鼻毛刀的产品成本。

2. 物流成本按订单计算。
   程序会读取飞书配置表里的“每单物流承载数量”。
   同一订单里同一个产品买多个，不会简单按销量重复计算物流。
   如果一个订单里有多个不同产品，整单只计算一次物流成本，并按各产品的候选物流成本比例分摊。

3. 寄样成本按样品单数量计算。

程序目前没有扣除达人佣金、广告费、平台佣金、平台服务费、支付手续费、退款售后、仓储人工、税费等费用。

所以这个利润只能用来快速判断产品是否还有毛利空间，不能直接当成最终利润或财务结算利润。

当前交付包默认支持：

1. 日本站
   - 本土店
   - 跨境店
   - 直邮店

2. 越南站
   - 本土店
   - 跨境店

3. 当前发给同事的压缩包只保留日本站和越南站日报所需目录。
   广告、商品卡、点击订单等其他旧模块目录不会打进压缩包。


二、文件夹结构说明
------------------

收到压缩包后，请先解压。解压后的文件夹建议长这样：

TikTokDailyReport
│
├─ TikTokDailyReport_v1.1.0.exe
│  双击这个文件运行程序。
│
├─ config
│  ├─ app_config.xlsx
│  │  控制哪些国家、哪些店铺需要运行。一般不用改。
│  │
│  ├─ cache
│  │  产品成本、物流成本、寄样成本等配置缓存。不要删除。
│  │
│  └─ .env
│     飞书在线配置读取凭证。如果没有这个文件，也可以使用 cache 缓存运行。
│     如果有这个文件，程序会优先从飞书刷新配置。
│
├─ data
│  ├─ data_JP
│  │  ├─ local
│  │  │  日本本土店订单 CSV 放这里。
│  │  │
│  │  ├─ cross-border
│  │  │  日本跨境店订单 CSV 放这里。
│  │  │
│  │  └─ direct
│  │     日本直邮店订单 CSV 放这里。
│  │
│  └─ data_VN
│     ├─ local
│     │  越南本土店订单 CSV 放这里。
│     │
│     └─ cross_border
│        越南跨境店订单 CSV 放这里。
│
└─ result
   程序生成的 Excel 报表会放在这里。


三、使用前准备
--------------

1. 先从 TikTok Shop 后台导出订单 CSV 文件。

   一般操作路径是：

   TikTok Shop 后台 → 订单 → 管理订单界面

   进入“管理订单界面”后，请先点击订单状态 Tab 里的“全部”。

   注意：
   管理订单界面下面有很多 Tab，例如：

   - 全部
   - 待支付
   - 待发货
   - 已发货
   - 已完成
   - 已取消

   请一定选择“全部”，不要只选择“待发货”或“已完成”。
   如果选错 Tab，导出的订单会不完整，报表数据也会不准。

   然后点击“筛选”，按需要筛选日期，例如本周、本月，或者自定义日期范围。

   筛选后，请确认页面上显示的订单数量是否符合预期。

   例如页面提示：

   找到 545 个订单

   这表示当前筛选条件下共有 545 个订单。

   确认订单数量没问题后，选择这个日期范围内的所有订单，然后点击导出。

   导出格式请选择 CSV。

   注意：
   - 请导出订单明细 CSV，不要导出 Excel 格式。
   - 日期范围要和你本次想统计的周期一致。
   - 如果要做两个周期对比，可以分别导出两个日期范围的 CSV，然后都放进同一个店铺目录。
   - 导出前请确认当前 Tab 是“全部”。
   - 导出前请确认页面订单数量和你预期的数量一致。

2. 打开 data 文件夹。

3. 找到你要统计的店铺目录。

   例如：

   日本直邮店：
   data\data_JP\direct

   越南跨境店：
   data\data_VN\cross_border

   重要说明：
   订单 CSV 一定要放到对应店铺的目录里，不能随便放。

   程序会根据文件所在目录判断它属于哪个国家、哪个店铺，然后读取对应的产品成本、物流成本、寄样成本配置。

   例如：
   - 日本本土店订单必须放到 data\data_JP\local
   - 日本跨境店订单必须放到 data\data_JP\cross-border
   - 日本直邮店订单必须放到 data\data_JP\direct
   - 越南本土店订单必须放到 data\data_VN\local
   - 越南跨境店订单必须放到 data\data_VN\cross_border
   不同店铺的物流成本、寄样成本、部分产品成本可能不一样。
   如果把日本直邮店订单放进日本本土店目录，程序会按本土店成本计算，结果会不准确。

4. 把 TikTok Shop 导出的订单 CSV 文件放进去。

5. 如果这个目录里有多个 CSV 文件，程序会把它们一起读取。

   注意：
   - 每个 CSV 会被当成一个单独周期。
   - 程序会自动生成周期对比。
   - 例如放入 6月第1周.csv 和 6月第2周.csv，就会生成第2周对比第1周的数据。

6. 如果不想统计旧文件，请先把旧 CSV 移走或删除。


四、如何运行程序
----------------

1. 双击：

   TikTokDailyReport_v1.1.0.exe

2. 程序打开后，会看到类似提示：

   ============================================
   TikTok Shop 日报生成工具
   ============================================

   请选择要运行的站点：
   1. 日本 JP
   2. 越南 VN
   3. 全部 all
   请输入数字后回车:

3. 根据需要输入数字，然后按回车。

   输入 1：
   只运行日本站。

   输入 2：
   只运行越南站。

   输入 3：
   日本和越南都运行。

4. 等待程序运行完成。

5. 如果看到类似下面的提示，说明已经生成成功：

   处理完成，报表已保存至 result\Daily_Performance_Report_JP_direct.xlsx

6. 打开 result 文件夹查看结果。


五、生成的报表在哪里
--------------------

所有结果都在 result 文件夹里。

常见文件名：

日本本土店：
Daily_Performance_Report_JP_local.xlsx

日本跨境店：
Daily_Performance_Report_JP_cross-border.xlsx

日本直邮店：
Daily_Performance_Report_JP_direct.xlsx

越南本土店：
Daily_Performance_Report_VN_local.xlsx

越南跨境店：
Daily_Performance_Report_VN_cross_border.xlsx

六、报表里的 Sheet 说明
-----------------------

1. Daily Summary

   按“文件名 + 日期”统计每天的整体汇总。
   可以看订单数、销量、销售额、成本、寄样数、寄样支出等。
   如果多个 CSV 里面都有同一天的数据，程序不会把它们直接混在同一行。

2. Period Comparison

   按 CSV 文件做周期对比。
   如果放了两个 CSV 文件，就会比较后一个周期和前一个周期。
   如果放了三个 CSV 文件，就会生成两组对比。

3. Daily Product Detail

   产品级明细。
   这里按照飞书配置表里的“产品大类”汇总，不再下钻到每个 SKU/规格。
   顶部是按“文件 + 产品大类”汇总的销售额、成本、预估毛利、预估毛利率。
   这里的预估毛利没有扣除达人佣金、广告费、平台费等费用。
   下方是每天每个产品大类的明细。

4. SKU Detail

   SKU/规格级明细。
   这里保留原来更细的 SKU 或规格数据。
   比如场景贴纸-3.0、场景贴纸-8.0、场景贴纸-9.0 会在这里分开显示。
   如果要排查某个规格是引流款还是利润款，可以看这个 Sheet。

5. Product Quantity Matrix

   产品销量矩阵。
   顶部是按“文件 + 产品”的销量汇总，方便复制。
   下方是“文件名 + 产品名称 + 日期”的每日销量矩阵。
   这样即使两个文件都有同一天，也能看出销量来自哪个文件。

6. Sample Statistics

   样品单统计。
   按“文件名 + 产品名称 + 日期”统计样品单数量。


七、常见问题
------------

问题 1：双击程序后提示找不到 app_config.xlsx

原因：
程序没有找到 config\app_config.xlsx。

解决：
新版程序会自动生成默认 app_config.xlsx。
如果仍然报错，请确认 TikTokDailyReport_v1.1.0.exe 同级目录下有 config 文件夹。


问题 2：提示没有配置飞书凭证，也缺少本地配置缓存

原因：
程序需要读取产品成本、物流成本、寄样成本配置。
这些配置来自 config\cache 或 config\.env。

解决办法二选一：

1. 确认 config\cache 文件夹存在，并且里面有类似这些文件：

   config_日本_本土店.csv
   config_日本_跨境店.csv
   config_日本_直邮店.csv
   config_越南_本土店.csv
   config_越南_跨境店.csv

2. 或者确认 config\.env 文件存在。


问题 3：提示某个店铺目录下未找到文件

原因：
对应店铺的 data 文件夹里没有 CSV 文件。

解决：
把 TikTok Shop 导出的订单 CSV 放到正确目录。

例如：

日本直邮店：
data\data_JP\direct

越南跨境店：
data\data_VN\cross_border


问题 4：为什么多个 CSV 会被一起读取

原因：
程序会读取同一个店铺目录下所有 CSV 文件。

说明：
如果你想比较两周数据，可以把两周的 CSV 都放进去。
如果你只想计算某一周，请只保留这一周的 CSV。


问题 5：报表结果看起来包含旧数据

原因：
data 目录里可能还留着旧 CSV 文件。

解决：
运行前检查对应店铺 data 文件夹。
不需要统计的旧 CSV 请移走或删除。


问题 6：运行时出现飞书读取失败

原因：
可能是网络问题、飞书权限问题，或者 .env 凭证缺失。

解决：
如果只是日常使用，优先检查 config\cache 是否存在。
有 cache 的情况下，通常不需要在线读取飞书。


问题 7：飞书表格已经更新了，但程序还是提示 SKU 没配置

原因：
如果程序目录下没有 config\.env，程序会使用 config\cache 里的本地缓存。
本地缓存可能还是旧数据。

解决：
如果希望程序每次优先读取飞书最新配置，请确认：

config\.env

这个文件存在，并且里面有飞书应用凭证。

有 config\.env 时，程序会优先从飞书刷新配置，并更新 config\cache。
没有 config\.env 时，程序会使用 config\cache 离线运行。


问题 8：程序运行完成后找不到结果

解决：
打开 result 文件夹。
所有生成的 Excel 都在 result 里面。


问题 9：程序窗口一闪而过

说明：
正常双击新版程序时，结束后会提示“按回车键退出”。
如果窗口直接消失，请尝试：

1. 右键文件夹空白处，选择“在终端中打开”。
2. 输入：

   TikTokDailyReport_v1.1.0.exe

3. 查看具体报错信息。


八、日常推荐操作流程
--------------------

每次统计前，建议按这个顺序：

1. 打开 TikTok Shop 后台。
2. 进入 订单 → 管理订单界面。
3. 点击订单状态 Tab 里的“全部”。
4. 点击“筛选”，筛选本次要统计的日期范围。
5. 确认页面显示的订单数量是否符合预期。
6. 选择日期范围内的所有订单，并导出 CSV。
7. 打开对应店铺的 data 文件夹。
8. 删除或移走不需要统计的旧 CSV。
9. 放入本次导出的订单 CSV。
10. 双击 TikTokDailyReport_v1.1.0.exe。
11. 输入 1、2 或 3，按回车。
12. 等待程序完成。
13. 打开 result 文件夹查看 Excel 报表。


九、不要随便删除的文件
----------------------

请不要删除：

config\app_config.xlsx
config\cache
data
result

如果删除了 config\cache，又没有 config\.env，程序将无法读取产品成本配置。
