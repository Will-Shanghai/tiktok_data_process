TikTokShopDataTool Windows EXE 打包说明
========================================

推荐方式：GitHub Actions 自动打包
------------------------------

代码推送到 GitHub 的 master 分支后，仓库会在 Windows 环境自动打包。

打包完成后，在 GitHub Actions 的 Artifacts 或 GitHub Release 的 Assets 中下载：

TikTokShopDataTool_v<版本号>_windows.zip

不要下载 Source code (zip)，那是源码包，不是可运行工具。


Windows 本机手动打包
-------------------

1. 安装 Python 3.11

安装时勾选 Add Python to PATH。

打开 CMD 或 PowerShell，进入项目根目录：

cd "C:\你的项目目录\tiktok_data_process"

项目根目录就是同时包含以下内容的目录：

main.py
sum_daily_order
sum_daily_conversion
VERSION

运行以下命令确认当前位置正确：

dir main.py, sum_daily_order, sum_daily_conversion, VERSION

2. 安装依赖

python -m pip install --upgrade pip
python -m pip install pandas requests python-dotenv openpyxl xlsxwriter pyinstaller -i https://pypi.tuna.tsinghua.edu.cn/simple --disable-pip-version-check

上面的命令使用清华大学 PyPI 镜像，适合国内网络环境。

如果需要长期在此电脑打包，可将 pip 默认镜像设为清华镜像，只需执行一次：

python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

设置后，后续安装依赖可使用：

python -m pip install pandas requests python-dotenv openpyxl xlsxwriter pyinstaller

Python 3.11 本体建议从 Python 官方安装器、公司软件中心或可信内部软件源安装。不要从不明第三方下载站获取 Python 安装包。

3. 一键生成发布包

在项目根目录双击或在 CMD 中执行：

build_windows_release.bat

脚本会自动打包日本、越南、墨西哥订单统计和商品每日转化四个模块，并复制当前源码中的：

- sum_daily_order\config\app_config.xlsx
- sum_daily_order\config\cache\（如有离线缓存）
- sum_daily_conversion\config\config.json
- sum_daily_conversion\config\product_sheet_mapping.csv
- VERSION 和使用说明

最终生成可分发的压缩包：

release\TikTokShopDataTool_v<版本号>_windows.zip

不要单独分发 dist 目录中的 EXE；请把这个 zip 包发送给同事，由同事完整解压后运行。

脚本从 VERSION 读取版本号。如果同版本的 release\TikTokShopDataTool_v<版本号> 已存在，脚本会停止，避免覆盖其中的 .env、输入数据或报表。更新 VERSION 后重新运行即可生成新的发布包。

发布包解压后的目录结构如下：

release\TikTokShopDataTool_v1.1.0\
├── TikTokShopDataTool_v1.1.0.exe
├── _internal\
├── VERSION
├── TikTokShopDataTool_使用说明.txt
├── config\
│   └── .env.example
├── sum_daily_order\
│   ├── config\
│   │   ├── app_config.xlsx
│   │   └── cache\
│   ├── data\
│   └── result\
└── sum_daily_conversion\
    ├── config\
    │   ├── config.json
    │   └── product_sheet_mapping.csv
    ├── data\
    └── result\

程序只读取发布包 EXE 同级的 config、sum_daily_order、sum_daily_conversion，不会联网下载或覆盖这两份转化配置。
配置更新流程为：在源码目录执行 git pull，确认配置已更新，修改 VERSION，运行 build_windows_release.bat，然后分发新的 zip 发布包。
GitHub Actions 也直接运行同一个 build_windows_release.bat，因此两种打包方式使用相同的模块、目录和配置复制规则。

不要复制或提交真实 .env。

如订单日报需要在线读取飞书配置，使用者在 EXE 同级新建：

config\.env

内容格式参考：

config\.env.example


4. 首次运行后的目录

首次打开 EXE 后，程序会自动创建：

sum_daily_conversion\data\日本本土店
sum_daily_conversion\data\日本跨境店
sum_daily_conversion\data\日本直邮一店
sum_daily_conversion\data\日本直邮二店

这些店铺目录来自 product_sheet_mapping.csv 的第一列“店铺”。
把商品数据 Excel 放到对应店铺目录，再运行“商品每日转化统计”。


5. 打包后自检

1. 双击 EXE，确认没有在 EXE 同级创建顶层 data 或 result。
2. 确认 sum_daily_conversion\data 下自动创建店铺目录。
3. 把一份商品数据 Excel 放进对应店铺目录后运行转化统计。
4. 确认 sum_daily_conversion\result 中生成结果 Excel。
5. 确认结果 Excel 包含“出单结构总览”和“点击转化总览”。
